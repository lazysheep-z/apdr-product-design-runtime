# APDR v0.4.0 — Product, UI and testing quality

- 将通用产品规则、UI 回归和版本测试接入原有 13 阶段，覆盖筛选日期、树表汇总、导航缓存、编辑日志、排程冲突、导入导出和任务下载。
- 区分检查完成、修复、复测、批准和上线；失败报告不能批准，可选 verification 校验必测项、当前版本证据及重大问题复测。
- 发布此前本地集成的设计工具适配层、固定上游资料与许可。平台 detector 二进制留在本地，使用前检查平台与校验和。
- 独立审查不补造正式阶段审批；纯文档任务不强制生成界面或运行浏览器。
- 发布范围仅通用框架与匿名示例，不含个人或客户资料、业务项目、原始测试记录、截图、凭据或本机配置。

验证：全包构建和类型检查通过；7 项质量与隐私回归、11 项原有 MCP/文档转换/浏览器/axe 回归通过；358 个固定上游文件哈希匹配；暂存文件隐私检查通过。

升级后运行 `npm run build` 并重连 MCP。可选工具依赖按 `docs/local-tools.md` 和 `skills/design-toolkit/references/libraries.md` 安装。新规则见 `docs/quality-workflow.md`。
