# 产品规则与验收条件

按实际功能选择以下规则，未确认的决策明确列为待确认，不直接改变业务口径。

| 功能 | 需求与验收应明确 |
|---|---|
| 筛选与搜索 | 单选/多选、草稿与已应用条件、自动/手动触发、去抖、重置、空结果和分页复位；摘要必须对应当前结果。移除查询按钮须验证触发链和实际结果。 |
| 日期时间 | 业务时区、最近 N 天是否含今天、自然日/滚动时段、起止边界、跨月跨年、单日/月/时刻字段类型；默认值、快捷项、取消和刷新应一致。共用组件初始化不得覆盖页面例外。 |
| 树表与汇总 | 层级及聚合粒度、父子重叠去重、仅末级累计、比率按总分子/总分母重算、零分母；明确同级排序、分组/记录分页、展开收起、筛选后的状态、分支加载/失败/重试/无子项。 |
| 入口与导航 | 直接地址、菜单、页签与缓存返回、关闭当前页签、浏览器前后退；入口预选是默认条件还是不可清除约束，须明确。角色入口和服务端权限分别定义。 |
| 编辑与日志 | 字段类型、精度、空值/零/负数/边界、编码文本与前导零；编辑→校验→保存→回显→刷新→日志。明确事件日志与每日快照的粒度、时间点、修改前后值和操作者字段，不能用模拟日志证明实际保存。 |
| 排程与冲突 | 时间段合法性、重叠边界、跨日处理、人员/资源冲突、编辑时排除自身、批量部分冲突、取消与重载一致性；冲突规则按产品确认，不硬编码历史组织或人员。 |
| 批量与导入 | 跨页选择、作用范围、重复记录、预览校验、部分失败、幂等/重试与撤销边界。配置或目标的固定层级、继承与汇总只有经产品确认后才能采用。 |
| 导出与任务 | 导出全部/筛选/已选范围、列与金额口径、空数据反馈、实际文件类型；创建→处理→成功/失败→下载→重下。再次下载应关联原任务文件，明确保留期限和跨设备能力。 |
| 指标与看板 | 数据来源、计算公式、金额单位/千分位/小数位、目标/实际/完成率语义；图表和明细同源、同范围、同分类映射。不得用改变数据口径来修复显示问题。 |

将适用项变成可执行 Given/When/Then 或等价验收条件，并关联功能 id、页面/组件与测试编号。无适用功能的行标记不适用并写原因，不生成无关工作。
